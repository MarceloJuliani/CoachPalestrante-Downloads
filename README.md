# Marcelo Juliani Coach — Downloads

Instaladores oficiais para Windows e Android.

## Versão 0.0.29 — PDFs e visualizações dos campos de Protocolos

Os PDFs da lista e da sessão passam a usar a configuração atual do cadastro, incluindo nomes personalizados, campos extras e ordem. As prévias, a busca e o aplicativo do coachee também mostram os campos configurados. Valores zero, respostas “Não” e anexos são preservados.

Para ativar no site, atualize o código e compile no VPS seguindo as [instruções de ativação](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.29/ATIVAR-NO-VPS.txt).

- [Instalador Windows x64 (.exe)](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.29/Marcelo.Juliani.Coach.Setup.0.0.29.exe)
- [Instalador Android (.apk)](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.29/Marcelo.Juliani.Coach.0.0.29-debug.apk)
- [Verificações SHA-256](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.29/SHA256SUMS.txt)
- [Todas as versões](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases)

Instale sobre a versão atual. O APK mantém a assinatura Android local das versões anteriores. Aguarde o instalador Windows terminar e o aplicativo reabrir antes de usar o atalho.

Acesse também [o sistema web](https://app.marcelojuliani.com.br).

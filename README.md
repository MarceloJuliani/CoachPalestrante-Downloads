# Marcelo Juliani Coach — Downloads

Instaladores oficiais para Windows e Android.

## Versão 0.0.20 — Atualização automática do desktop

No Windows, o aplicativo avisa ao abrir quando há uma versão nova. Atualizar agora
baixa com progresso, confere o instalador e inicia a instalação. Ao terminar, o
aplicativo reabre. Depois adia o aviso até a próxima abertura.

Instale esta versão uma vez sobre a instalação atual para habilitar o novo fluxo
nas próximas atualizações. Os dados locais são preservados.

- [Instalador Windows x64 (.exe)](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.20/Marcelo.Juliani.Coach.Setup.0.0.20.exe)
- [Instalador Android (.apk)](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.20/Marcelo.Juliani.Coach.0.0.20-debug.apk)
- [Verificações SHA-256](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.20/SHA256SUMS.txt)
- [Todas as versões](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases)

Acesse também [o sistema web](https://app.marcelojuliani.com.br).

O APK Android é distribuído para instalação direta e usa a mesma assinatura do APK
local 0.0.19. O instalador Windows permite atualizar a instalação existente.

A versão 0.0.20 preserva as correções de contagem do painel, pop-ups, proteção das sessões,
privacidade das anotações do coach e conteúdo completo do PDF das ferramentas.

# Marcelo Juliani Coach — Downloads

## Versão 0.0.33 — Abertura dos cadastros dinâmicos

Os menus dos cadastros dinâmicos salvos aparecem na primeira renderização. As definições são atualizadas em paralelo, sem aguardar clientes, arquivos e os demais dados. No primeiro acesso sem cache é necessária uma consulta das definições. Criar e editar um cadastro atualiza o menu assim que a API confirma. Clientes, fichas preenchidas e sessões permanecem privados para o coach responsável.

Instale sobre a versão atual. O APK usa o mesmo certificado dos APKs anteriores do canal público. Arquivos antigos dos artefatos internos do GitHub podem ter outro certificado; se houver aviso de assinatura diferente, preserve a instalação para diagnóstico. O tablet com versão 0.0.30 ou posterior pode consultar pelo botão **Verificar atualizações**; versões anteriores precisam da instalação manual do APK uma vez.

Acesse também [o sistema web](https://app.marcelojuliani.com.br). Se necessário, atualize o VPS conforme as instruções.

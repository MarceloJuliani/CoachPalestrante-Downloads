# Marcelo Juliani Coach — Downloads

Instaladores oficiais para Windows e Android.

## Versão 0.0.18 — Pop-ups e proteção das sessões

Avisos e confirmações em pop-ups integrados ao aplicativo. Sessões em andamento são
retomadas, mantendo a mesma identificação ao salvar. A API bloqueia novas duplicidades.
Cada coach possui seus próprios clientes, atendimentos, financeiro e configurações.

- [Instalador Android (.apk)](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.18/Marcelo.Juliani.Coach.0.0.18-debug.apk)
- [Verificações SHA-256](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.18/SHA256SUMS.txt)
- [Todas as versões](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases)

Acesse também [o sistema web](https://app.marcelojuliani.com.br).

O APK Android é distribuído para instalação direta e usa a mesma assinatura do APK
local 0.0.17. O instalador Windows permite atualizar a instalação existente.

A API do site deve estar na versão 0.0.18 para aplicar a proteção completa das sessões.
Entradas duplicadas anteriores são preservadas para análise de suas anotações e respostas.

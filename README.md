# Marcelo Juliani Coach — Downloads

Instaladores oficiais para Windows e Android.

## Versão 0.0.28 — Campos das ferramentas de Protocolos

Ao incluir e editar ferramentas dos cadastros dinâmicos, o formulário respeita os nomes, tipos, ordem, opções e campos obrigatórios definidos no cadastro. Campos extras, anexos e vínculos das sessões são preservados.

Para ativar no site, atualize o código e compile no VPS seguindo as [instruções de ativação](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.28/ATIVAR-NO-VPS.txt).

- [Instalador Windows x64 (.exe)](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.28/Marcelo.Juliani.Coach.Setup.0.0.28.exe)
- [Instalador Android (.apk)](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.28/Marcelo.Juliani.Coach.0.0.28-debug.apk)
- [Verificações SHA-256](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.28/SHA256SUMS.txt)
- [Todas as versões](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases)

Instale sobre a versão atual. O APK mantém a assinatura Android local das versões anteriores. Aguarde o instalador Windows terminar e o aplicativo reabrir antes de usar o atalho.

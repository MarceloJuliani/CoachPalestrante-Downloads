# Marcelo Juliani Coach — Downloads

Instaladores oficiais para Windows e Android.

## Versão 0.0.21 — Fotos e ícones no desktop

Corrigido o carregamento das fotos dos coachees e dos ícones enviados para os menus
no desktop. A correção também cobre imagens em formulários, sessões, galerias e
relatórios, usando os arquivos existentes no servidor.

No desktop 0.0.20, feche e abra o aplicativo e escolha Atualizar agora quando a
versão nova for oferecida. O EXE também atualiza a instalação existente.

- [Instalador Windows x64 (.exe)](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.21/Marcelo.Juliani.Coach.Setup.0.0.21.exe)
- [Instalador Android (.apk)](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.21/Marcelo.Juliani.Coach.0.0.21-debug.apk)
- [Verificações SHA-256](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases/download/v0.0.21/SHA256SUMS.txt)
- [Todas as versões](https://github.com/MarceloJuliani/CoachPalestrante-Downloads/releases)

Acesse também [o sistema web](https://app.marcelojuliani.com.br).

O APK Android é distribuído para instalação direta e usa a mesma assinatura do APK
local 0.0.20. O instalador Windows permite atualizar a instalação existente.

A versão 0.0.21 preserva as correções de contagem do painel, pop-ups, proteção das sessões,
privacidade das anotações do coach e conteúdo completo do PDF das ferramentas.

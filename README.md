# Marcelo Juliani Coach — Downloads

Instaladores oficiais para Windows e Android.

## Versão 0.0.19 — Contagem de clientes no painel

O total de Clientes ativos acompanha a lista de coachees do Processo de Coaching,
sem adicionar cadastros de outros módulos. Esta correção preserva os cadastros e
históricos. Cada coach possui seus próprios clientes, atendimentos e configurações.

Acesse também [o sistema web](https://app.marcelojuliani.com.br).

O APK Android é distribuído para instalação direta e usa a mesma assinatura do APK
local 0.0.18. O instalador Windows permite atualizar a instalação existente.

A versão 0.0.19 preserva as correções anteriores de pop-ups, proteção das sessões,
privacidade das anotações do coach e conteúdo completo do PDF das ferramentas.
